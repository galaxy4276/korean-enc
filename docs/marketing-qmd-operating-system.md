# Korea I&C Marketing QMD Operating System

## 목적

코리아이앤씨의 병원 클린룸/BCR 시공 고객을 지속적으로 수집하고, qmd 기반 지식베이스로 축적하여 이메일, 전화, 검색광고, 제휴영업에 반복 활용한다.

이 시스템의 목표는 단순한 연락처 목록이 아니라 다음 네 가지를 계속 쌓는 것이다.

1. 누가 고객인지
2. 지금 왜 필요할 가능성이 있는지
3. 어떤 메시지로 접근해야 하는지
4. 연락 이후 어떤 상태인지

## 고객 분류 체계

### 1차 고객: 직접 발주 가능성이 높은 고객

| 세그먼트 | 예시 | 주요 니즈 | 우선순위 |
|---|---|---|---|
| 개원 준비 의원 | 성형외과, 정형외과, 안과, 산부인과, 치과, 수술 중심 피부과 | 개원 일정, 인허가, 수술실 완성도, 빠른 견적 | A |
| 수술실 보유 중소병원 | 전문병원, 수술 중심 병원, 재활/정형/척추 병원 | 수술실 증설, 리모델링, 감염관리 대응 | A |
| 병원 시설/구매 담당 | 시설팀, 총무팀, 구매팀, 행정부 | 견적 비교, 공정 범위, 납기, 하자 대응 | A |
| 감염관리 필요 기관 | 격리실, 중환자실, 음압/양압 공간 필요 병원 | 감염관리, 공조, 구역 분리 | B |

### 2차 고객: 리드 공급원 또는 협력사

| 세그먼트 | 예시 | 주요 니즈 | 우선순위 |
|---|---|---|---|
| 병원 개원 컨설팅 업체 | 개원 대행, 입지/장비/인허가 컨설팅 | 신뢰할 수 있는 수술실 전문 시공 파트너 | A |
| 병원 인테리어 업체 | 일반 병원 인테리어, 메디컬 빌딩 전문 업체 | BCR/수술실 전문 영역 외주 | A |
| 건축사사무소 | 의료시설 설계 경험 보유 사무소 | 설계 이후 전문 시공 협력 | B |
| 의료기기 업체 | 수술대, 무영등, 멸균기, 공조장비, 가스패널 | 장비 설치 환경과 시공 협업 | B |
| HVAC/공조 업체 | 클린룸 공조, 필터, 덕트, 차압 관리 | 병원 클린룸 시공 공동 대응 | B |

### 3차 고객: 장기 nurture 대상

| 세그먼트 | 예시 | 주요 니즈 | 우선순위 |
|---|---|---|---|
| 요양병원/검진센터 | 직접 수술실 수요는 낮지만 리모델링 가능 | 시설 개선, 감염관리 | C |
| 일반 의원 | 비수술 중심 진료과 | 개원/이전 시점 포착 | C |
| 메디컬 빌딩 시행/분양 | 병원 입점 정보 보유 | 입점 의원 소개, 제휴 | C |

## 리드 상태 정의

| 상태 | 의미 | 다음 액션 |
|---|---|---|
| `new` | 새로 발견했지만 검증 전 | 홈페이지/전화번호/이메일 검증 |
| `qualified` | 대상 업종과 니즈가 맞음 | 1차 접근 |
| `contacted` | 이메일/전화/문자 중 하나로 접촉 | 반응 기록 |
| `interested` | 상담/견적 가능성 있음 | 현장 실측 또는 상세 상담 |
| `proposal` | 견적/제안 진행 | 의사결정자와 일정 확인 |
| `won` | 수주 | 사례화 가능 여부 확인 |
| `lost` | 실패 | 실패 사유 기록 |
| `nurture` | 당장 수요는 없지만 장기 관리 | 분기별 콘텐츠 발송 |
| `do_not_contact` | 수신거부/연락금지 | 모든 캠페인 제외 |

## 리드 데이터 스키마

초기에는 스프레드시트나 CSV로 운영하고, qmd에는 리드 목록과 분석 문서를 함께 인덱싱한다.

```csv
lead_id,org_name,segment,priority,status,region,department_or_specialty,decision_maker_role,website,phone,email,source,need_signal,last_contacted_at,next_action_at,opt_in_status,do_not_contact,notes
```

### 필드 기준

| 필드 | 설명 |
|---|---|
| `segment` | `opening_clinic`, `surgical_hospital`, `facility_team`, `opening_consultant`, `medical_interior`, `architect`, `medical_device`, `hvac`, `long_term` |
| `priority` | A/B/C |
| `need_signal` | 개원, 이전, 리모델링, 수술실 증설, 감염관리, 협력 가능성 등 |
| `source` | 네이버지도, 병원 홈페이지, 협회, 전시회, 소개, 광고 유입 등 |
| `opt_in_status` | `unknown`, `consented`, `transaction_exception`, `not_allowed`, `unsubscribed` |
| `do_not_contact` | 수신거부 또는 연락금지면 `true` |

## qmd 지식베이스 구조

repo 안에는 운영 원천 자료를 두고, qmd 컬렉션은 이 폴더를 인덱싱한다.

```text
marketing/
  leads/
    leads.csv
    suppressed.csv
  research/
    2026-06-region-hospital-cleanroom-market.md
    2026-06-opening-clinic-keywords.md
  campaigns/
    2026-06-opening-clinic-email.md
    2026-06-medical-interior-partner.md
  playbooks/
    lead-qualification.md
    first-contact-script.md
    follow-up-rules.md
  reports/
    weekly-marketing-brief.md
```

추천 qmd 컬렉션명:

```bash
qmd update -c korean-enc
qmd embed -c korean-enc
qmd query "성형외과 개원 준비 고객에게 보낼 첫 이메일" -c korean-enc
qmd query "병원 인테리어 협력사 제휴 메시지" -c korean-enc
```

qmd 컬렉션이 아직 없다면 `marketing/`과 `docs/`를 포함하는 `korean-enc` 컬렉션을 추가한다. 운영 중에는 새 리드 조사, 캠페인 결과, 통화 메모, 실패 사유를 모두 Markdown으로 남기고 qmd에 다시 넣는다.

## 에이전트 역할

### 1. Market Research Agent

목표: 고객 후보와 시장 신호를 수집한다.

반복 작업:

- 지역별 병원/의원/협력사 후보 조사
- 신규 개원, 이전, 리모델링, 의료기기 설치, 메디컬 빌딩 입점 신호 수집
- 후보별 세그먼트와 우선순위 부여
- `marketing/research/`에 조사 요약 저장

출력:

- 신규 리드 CSV
- 세그먼트별 시장 메모
- 광고 키워드 후보

### 2. Lead Qualification Agent

목표: 연락할 가치가 있는 고객인지 판단한다.

판단 기준:

- 수술실/BCR/격리실/중환자실 수요 가능성
- 예산과 의사결정권자 접근 가능성
- 연락처 신뢰도
- 최근 니즈 신호
- 법적/운영적 연락 가능성

출력:

- A/B/C 우선순위
- 첫 접근 채널
- 추천 메시지 각도

### 3. Campaign Agent

목표: 세그먼트별 이메일, 문자, 전화 스크립트, 광고 문안을 만든다.

캠페인 유형:

- 개원 준비 의원용
- 수술실 리모델링 병원용
- 병원 인테리어 협력사용
- 의료기기/HVAC 제휴사용
- 감염관리/격리실 대응용

출력:

- 이메일 제목 5개
- 본문 2종
- 전화 첫 멘트
- 랜딩페이지 CTA 개선안
- 광고 키워드와 문안

### 4. CRM Follow-up Agent

목표: 연락 후 상태를 잃어버리지 않게 관리한다.

반복 작업:

- 이번 주 연락 대상 산출
- 7일/14일/30일 후속 연락 추천
- 관심 고객과 장기관리 고객 분리
- 수신거부, 연락금지, 실패 사유 반영

출력:

- 주간 follow-up 리스트
- 놓친 리드 알림
- 다음 액션 제안

### 5. Insight Agent

목표: 누적된 리드와 캠페인 결과에서 다음 전략을 만든다.

반복 작업:

- 어떤 세그먼트가 반응하는지 분석
- 어떤 메시지가 견적 문의로 이어지는지 정리
- 웹사이트/랜딩페이지 수정 제안
- 광고 예산 배분 제안

출력:

- 주간 마케팅 브리프
- 웹사이트 개선 backlog
- 세그먼트별 winning message

## 마케팅 메시지 방향

### 개원 준비 의원

핵심 메시지:

- 개원 일정에 맞춘 수술실/BCR 시공
- 의료시설 경험 기반의 공정 관리
- 수술실, 격리실, 중환자실 등 용도별 대응

피해야 할 메시지:

- 과도한 최저가 강조
- 근거 없는 인증/성능 보장 표현
- 일반 인테리어처럼 보이는 표현

### 수술실 보유 병원

핵심 메시지:

- 운영 중 병원의 단계별 리모델링 대응
- 감염관리와 공조를 고려한 시공
- 현장 조건 기반 견적과 공정 범위 명확화

### 협력사

핵심 메시지:

- 병원 클린룸/BCR 전문 시공 파트너
- 일반 병원 인테리어가 처리하기 어려운 수술실/격리실 영역 보완
- 의료기기 설치 환경까지 고려한 협업

## 광고/이메일 컴플라이언스 메모

광고성 이메일과 문자는 리드 수집보다 법적 운영 기준이 더 중요하다. 2024년 KISA는 정보통신망법 안내서 개정본을 발간했고, 광고성 정보 전송 규정과 처벌 강화 내용을 안내했다.

운영 원칙:

- 광고성 정보는 원칙적으로 사전 수신동의가 필요하다.
- 이메일 광고에는 수신거부 방법을 쉽게 선택할 수 있는 기술적 조치가 필요하다.
- 수신거부 의사가 도달한 뒤에는 광고 전송을 중단한다.
- 전송자 명칭, 연락처, 수신거부 방법은 이미지가 아니라 텍스트로 표시한다.
- 이메일 수신거부 안내는 한글과 영어 모두 표기해야 한다.
- 수신거부/연락금지 목록은 모든 캠페인 전에 반드시 제외한다.

실무적으로는 “무작위 대량 발송”이 아니라, 합법적으로 수집한 문의/제휴/기존 거래/명확한 동의 기반 리드를 중심으로 운영해야 한다. 공개된 이메일을 발견했다는 사실만으로 광고성 메일을 마음대로 보내도 된다고 보면 안 된다.

참고:

- KISA 보도자료: https://www.kisa.or.kr/402/form?lang_type=KO&page=6&postSeq=2382
- KISA/BCC 불법스팸 방지를 위한 정보통신망법 안내서: https://www.ktsmartmsg.com/Files/AntiSpam_Law_Guide_v7.pdf
