5. Motion

motion (framer-motion) 라이브러리 기반 애니메이션 패턴

fadeInUp

섹션/카드 스크롤 등장

y: 30 -> 0, opacity: 0 -> 1, duration: 0.8s

stagger

카드 순차 등장

staggerChildren: 0.1s

countUp

신뢰 수치 카운팅

0 -> target, duration: 2s

slideIn

메뉴 오버레이

translateY: -100vh -> 0, 0.3s ease

crossFade

Before/After 전환

opacity crossfade, 0.3s

overlay

포트폴리오 호버

opacity: 0 -> 1, 0.1s
모션 원칙: "과하지 않되 세련되게." 모든 등장 애니메이션은 IntersectionObserver(뷰포트 진입)로 트리거. 33design.space는 WOW.js + fadeInUp 1.5s를 사용하지만, 우리는 motion 라이브러리로 구현.
