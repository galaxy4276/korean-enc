비즈니스 웹사이트 기획안

병원 클린룸(BCR) 전문 시공 기업의 신뢰 구축과 계약 전환을 위한 웹사이트 구조 기획서

작성일: 2026.03.24 버전: 1.0 (기획 초안) 범위: 사이트맵 · 페이지 구성 · 인터랙션 · 전환 설계

1. 프로젝트 개요

웹사이트의 목적, 타겟, 핵심 전략을 정의합니다.

프로젝트 목적

코리아이앤씨의 전문성과 시공 실적을 체계적으로 보여주어 병원 관계자의 신뢰를 확보하고, 견적 문의 → 계약으로 이어지는 전환을 유도하는 비즈니스 웹사이트를 구축한다.

타겟 오디언스 (2-Track)

Track A — 의사결정권자
병원 원장, 경영진, 행정팀장
→ 관심사: 신뢰성, 실적 규모, 업체 안정성
→ 제공: 회사 소개, 핵심 수치, 고객 후기
Track B — 실무 담당자
시설관리 담당자, 구매/조달팀
→ 관심사: 시공 스펙, 공정 과정, 가격 경쟁력
→ 제공: Before-After, 공정 단계, 서비스 상세

핵심 메시지 전략

3가지 핵심 가치를 사이트 전반에 걸쳐 반복적으로 전달합니다.

🏗️ 전문성 — BCR 클린룸 특화 📋 경험 — 20년+ 현장 노하우 🤝 신뢰 — 정직한 견적, 끝까지 책임

전환(CTA) 목표

Primary CTA: 전화 바로 걸기 (모바일 탭투콜) + 상세 문의폼
Secondary CTA: 카카오톡 채널 문의 (선택적 추가 검토)
KPI: 월간 문의 건수, 전화 연결 수, 문의폼 전환율

4. 서브 페이지별 기획

회사소개 · 서비스 안내 · 시공사례 · 문의하기

📌 회사소개 페이지

기업의 안정성과 진정성을 느끼게 하는 페이지. 경영진이 주로 확인하는 영역.

1

회사 비전 & 미션

"정직한 시공, 끝까지 책임" — 회사 핵심 가치를 시각적 배너로 표현. 배경에 완공 수술실 사진.

2

대표이사 인사말

남기태 대표의 인사말 전문. 좌측에 대표 사진(선택), 우측에 텍스트 레이아웃. 20년 경험 강조.

3

회사 연혁 타임라인

2023년 설립 → 주요 시공 실적 타임라인. 짧은 연혁이지만 "경험의 깊이"를 보여주는 구성.

4

인증 & 면허 영역 (예약)

현재 미확보 상태. 향후 건설업면허, ISO인증 등 확보 시 로고/인증마크 배치 영역을 미리 설계.

📌 서비스 안내 페이지

실무 담당자가 기술적 판단을 위해 확인하는 페이지. 전문성을 구체적으로 전달.

1

BCR 클린룸이란?

BCR(Biological Clean Room)의 개념을 비전문가도 이해할 수 있도록 설명. 인포그래픽 활용. 생물학적 입자·비생체 입자 제어, 살균/멸균 개념 시각화.

2

시공 분야별 상세

수술실 / 무균실 / 중환자실 / 격리실 — 각 분야별 탭(Tab) UI로 구성. 분야별 시공 특성, 적용 기준, 대표 사진.

3

공정 프로세스 상세

6단계 공정을 각각 상세 설명. 단계별 실제 사진 포함. 현장실측 → 설계·견적 → 철거·바닥 → 클린룸시공 → 검증·인수 → AS.

4

시공 후 유지보수 안내

AS 정책, 정기 점검 서비스 안내. 시공 후에도 관리해준다는 점을 강조하여 장기 파트너십 인식.

💡 인터랙션: 시공 분야별 탭(Tab) 전환 시 콘텐츠가 부드럽게 교체. 공정 프로세스는 스텝 클릭 시 해당 공정 사진이 확대.

5. 주요 인터랙션 & UX 요소

사용자 경험을 강화하는 인터랙션 설계

📱

모바일 Sticky CTA Bar

모바일 하단에 항상 고정되는 "전화하기 | 문의하기" 바. 어떤 페이지에서든 즉시 전환 가능. 스크롤 방향에 따라 표시/숨김 처리하여 콘텐츠 방해 최소화.

🔀

Before-After 이미지 슬라이더

시공 전/후 사진을 하나의 프레임에서 드래그(모바일: 스와이프)로 비교. 시공사례의 핵심 인터랙션. 라이브러리 예시: twentytwenty.js, cocoen 등.

🔢

카운트업 애니메이션

메인 페이지 신뢰 수치 섹션. 뷰포트 진입 시(Intersection Observer) 숫자가 0에서 목표값까지 카운팅. 시선을 사로잡고 데이터 신뢰감 부여.

📜

스크롤 기반 등장 애니메이션

각 섹션/카드가 스크롤 시 아래에서 위로 fade-in. 과하지 않은 수준으로 적용하여 세련된 인상. AOS(Animate On Scroll) 라이브러리 활용 가능.

🖼️

시공사례 카드 호버 효과

데스크톱에서 프로젝트 카드에 마우스를 올리면 Before→After로 이미지가 크로스페이드 전환. 모바일에서는 탭 시 전환.

⬆️

스크롤 프로그레스 & 네비게이션

메인 랜딩 페이지 우측에 현재 섹션 위치를 나타내는 도트 네비게이션(선택적). 헤더는 스크롤 다운 시 축소(compact header)되어 콘텐츠 공간 확보.

플로팅 문의 버튼

6. 사용자 여정 시나리오

두 타겟의 예상 탐색 경로

시나리오 A — 병원 원장 (의사결정권자)

검색/소개로 유입
→
Hero에서 첫인상
→
신뢰 수치 확인
→
대표 인사말 확인
→
📞 전화 문의

핵심 포인트: 첫 화면의 임팩트와 수치 데이터로 빠르게 신뢰를 형성하고, 전화로 바로 연결. 상세한 탐색보다는 "믿을 만한 업체인가"를 빠르게 판단.

시나리오 B — 시설관리 담당자 (실무자)

검색으로 유입
→
서비스 상세 확인
→
시공사례 탐색
→
Before-After 비교
→
공정 프로세스 확인
→
✉️ 문의폼 제출

핵심 포인트: 구체적인 시공 스펙과 사례를 꼼꼼히 비교한 뒤, 문의폼에 상세 정보(공사유형, 규모)를 기입하여 제출. 비교 자료로 경영진에게 보고.

7. 기술 및 운영 고려사항

개발 시 참고할 기본 요구사항

항목 내용
반응형 디자인 모바일 퍼스트 설계 필수. 병원 관계자가 이동 중 모바일로 탐색할 가능성 높음. 브레이크포인트: 360px / 768px / 1200px
페이지 속도 시공 사진이 많으므로 이미지 최적화(WebP), Lazy Loading 필수. LCP 2.5초 이내 목표
SEO 주요 키워드: "병원 클린룸 시공", "수술실 시공 업체", "BCR 클린룸", "병원 수술실 공사". 메타태그, 구조화 데이터(LocalBusiness) 적용
문의폼 백엔드 폼 제출 시 이메일 알림(관리이사 + 대표) + DB 저장. 자동 접수 확인 메일/문자 발송
애널리틱스 GA4 설치. 이벤트 추적: 전화 클릭, 문의폼 제출, 시공사례 상세 열람, Before-After 슬라이더 사용
콘텐츠 관리 시공사례 추가가 잦을 수 있으므로 CMS(워드프레스 등) 또는 관리 페이지 고려. 초기에는 정적 사이트도 가능
SSL / 보안 HTTPS 필수. 문의폼 개인정보 수집 시 개인정보처리방침 페이지 필요
